# Your Morning Cup — Phase 1 baseline

Responsive black-and-white standalone demonstration, with a single finite sample cup, Discover and Deep Dive navigation, source links, and an under-construction Library.

Open `index.html` locally or use GitHub Pages. No accounts, persistent storage, live personalization, or automated refills are implemented.

Prototype sample dated October 24, 2026. Content and links should be independently verified before broader publication. Test on mobile Safari, tablet, desktop, and assistive technology.


## Structured catalog experiment (November 2026)

The shared edition lives in content/catalog.json. catalog-loader.js renders its Discover cards and featured Deep Dive into the existing layout. Static content remains in index.html as a fallback if JSON loading fails. The catalog is a manually curated demonstration, not automated or personalized. The backup branch backup/pre-json-catalog-2026-11-02 preserves the original working site. Verify source links and editorial standards before updating edition data; never advance date without editorial review.
